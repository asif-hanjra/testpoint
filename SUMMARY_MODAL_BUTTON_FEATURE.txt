🔄 HOW IT WORKS:

Flow:
  1. SBERT processing completes
  2. Summary Modal appears
  3. Shows groups by similarity percentage
  4. If >1000 groups → Purple "Submit All" button appears
  5. User clicks button
  6. Background submission starts
  7. Progress modal shows
  8. All groups submitted with auto-selection
  9. Success toast appears
  10. Navigates to review page

Auto-Selection Logic:
  - Priority 1: Files with year metadata
  - Priority 2: Files with smallest number
  - One file selected per group
  - Same logic as normal auto-selection
