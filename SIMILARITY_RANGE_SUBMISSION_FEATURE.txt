🔄 HOW IT WORKS:

Flow:
  1. SBERT completes → Summary Modal appears
  2. User sees similarity range selector
  3. Default range: 100.0% - 99.0%
  4. User can adjust sliders to change range
  5. Count updates in real-time
  6. User clicks "Submit X Groups"
  7. Only groups in selected range are submitted
  8. Progress modal shows filtered count

Filtering Logic:
  - For each group, check max_similarity
  - Round to 0.1% precision
  - Include if: start >= similarity >= end
  - Example: 100.0% - 99.0% includes:
    • 100.0% ✅
    • 99.9% ✅
    • 99.0% ✅
    • 98.9% ❌
